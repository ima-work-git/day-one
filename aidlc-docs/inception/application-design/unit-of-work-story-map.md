## ユニット別ストーリーカバレッジ

### Unit 1: インフラ基盤
全ストーリーの前提となるインフラを提供。直接対応するユーザーストーリーはないが、すべてのストーリーの実行基盤。

| US-103 / US-203 | 音声録音 → クローンボイス生成 |

| US-402 / US-502 | 将来拡張の対話機能 |

### Unit 3: 記録・ユーザー管理
| ストーリー | 担当機能 |

| US-102 / US-202 | フォーマットカスタマイズ |
