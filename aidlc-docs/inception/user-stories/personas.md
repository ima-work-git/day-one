# ペルソナ定義 — Day 1

## ペルソナ優先度
1. **企業従業員**（BtoBエンドユーザー）— 最重要
2. **個人ユーザー**（BtoCエンドユーザー）
3. **企業管理者**（BtoB導入・管理担当）
4. **学生**（教育機関経由）
5. **スポーツ選手**（将来拡張）

---

## ペルソナ 1: 田中 誠（企業従業員）【最重要】

| 項目 | 内容 |
|---|---|
| **年齢** | 24歳 |
| **職種** | 入社2年目・営業職 |
| **利用文脈** | 入社2年目の節目研修でDay 1を使った振り返りが課題として課された。入社初日に記録した自分と向き合う機会を与えられた |
| **課題** | 2年目になり、業務に慣れた反面、最初の熱量や「なぜこの会社を選んだか」が曖昧になってきた。疲れや慣れで、入社当時とは別人のような感覚がある |
| **動機** | 会社の研修プログラムの一環として振り返りが義務付けられた。最初は「面倒だな」と思っていたが、いざ過去の自分の声を聞いて衝撃を受けた |
| **テクノロジー習熟度** | スマートフォン・Webアプリは日常的に使う |
| **利用シーン** | 研修の振り返りセッション中、その後も自発的に仕事で行き詰まったときに利用 |

**ゴール**: 入社時の熱量・動機を思い出し、今の仕事に向き合い直す
**フラストレーション**: 「初心に戻れ」と言われても、具体的にどうすればいいかわからない。日記や手帳は続かない
**Day 1 での期待**: 研修で強制的に向き合ったことで気づきを得た。その後は自発的に使うようになる

## ペルソナ 2: 佐藤 美咲（個人ユーザー・ダイエット）

| 項目 | 内容 |
|---|---|
| **年齢** | 32歳 |
| **職種** | フリーランスデザイナー |
| **利用文脈** | ダイエット開始時に自分でDay 1に登録 |
| **課題** | 3ヶ月で5kg減を目標にしたが、2ヶ月目で挫折しそう |
| **動機** | 「始めたときの悔しさ・決意を忘れたくない」 |
| **テクノロジー習熟度** | デジタルツールに慣れている |
| **利用シーン** | 夜、食欲に負けそうなとき。週末の怠けたいとき |

**ゴール**: ダイエット開始時の強い動機を維持し、目標を達成する
**フラストレーション**: 日記やメモは続かない。過去の自分の記録を見返す気になれない
**Day 1 での期待**: 自分の声で語りかけられることで、テキストを読むより感情的に刺さる

## ペルソナ 3: 山田 課長（人材開発・育成担当）

| 項目 | 内容 |
|---|---|
| **年齢** | 42歳 |
| **職種** | 人事部 人材開発・育成担当 課長 |
| **利用文脈** | 社員の成長支援・キャリア自立を促す研修プログラムの企画担当としてDay 1を導入検討 |
| **課題** | 入社時の研修は充実しているが、数年後に社員が「なぜこの会社を選んだか」「何をしたかったか」を見失うケースが多い。自分を見つめ直す機会を定期的に提供したいが、手動でのフォローには限界がある |
| **動機** | 社員一人ひとりが自分のキャリアと向き合い、モチベーションを自律的に維持できる仕組みを作りたい。会社が「気づきの場」を提供することで、社員の成長と組織の活性化につなげたい |
| **テクノロジー習熟度** | 業務システムは使えるが、新しいツールの習得には時間がかかる |
| **利用シーン** | 新入社員研修の企画時、2〜3年目社員向けのキャリア研修設計時、年度の人材育成計画策定時 |

**ゴール**: 社員が自分を見つめ直す機会を定期的に提供し、自律的なモチベーション維持と成長を支援する
**フラストレーション**: 研修後のフォローアップ手段がない。「頑張れ」と言うだけでは社員の内発的動機には届かない
**Day 1 での期待**: 入社時の記録を数年後に自動で届けることで、社員自身が「あのときの自分」と向き合う機会を仕組みとして提供できる。離職率への直接効果より、社員の自己認識・成長実感・エンゲージメント向上を期待する

## ペルソナ 4: 鈴木 健太（学生・将来拡張）

| 項目 | 内容 |
|---|---|
| **年齢** | 高校1年生（登録時）→ 高校3年生（振り返り時） |
| **職種** | 高校生 |
| **利用文脈** | 高校1年生のとき、学校の授業（キャリア教育・総合学習）でDay 1への登録が課題として出された。「将来の夢・なりたい自分」を記録した。高校3年生になり受験期に、先生から「1年生のときの自分を振り返ってみよう」と促されて再び開いた |
| **課題** | 受験勉強が辛くなり、「なぜこの大学を目指しているのか」「そもそも自分は何がしたいのか」がわからなくなってきた |
| **動機** | 先生から授業の一環として振り返りを促された。最初は義務感だったが、高1の自分の声を聞いて「あのとき自分はこんなことを考えていたのか」と驚き、感化された |
| **テクノロジー習熟度** | スマートフォンネイティブ |
| **利用シーン** | 模試で落ち込んだとき、勉強をサボりたいとき、進路に迷ったとき |

**ゴール**: 高1のときに抱いていた夢・動機を思い出し、受験を乗り越える
**フラストレーション**: 親や先生に「頑張れ」と言われても響かない。自分でも「なぜ頑張るのか」が言語化できていない
**Day 1 での期待**: 2年前の自分の声に感化されることで、他者の言葉より深く刺さる。「あのときの自分に恥ずかしくない自分でいたい」という気持ちが生まれる

## ペルソナ 5: 中村 アスリート（スポーツ選手・将来拡張）

| 項目 | 内容 |
|---|---|
| **年齢** | 24歳 |
| **職種** | プロ野球選手 |
| **利用文脈** | 大きな試合で打てなかった直後の悔しさを記録 |
| **課題** | 日々の練習のモチベーションが波打つ。あの悔しさを忘れてしまう |
| **動機** | 「あの試合の悔しさを忘れたくない。あの気持ちを練習の原動力にしたい」 |
| **テクノロジー習熟度** | スマートフォンは使うが、複雑なアプリは苦手 |
| **利用シーン** | 練習前、試合前、スランプのとき |

**ゴール**: 悔しさ・決意を原動力に変え、継続的に努力する
**フラストレーション**: 時間が経つと感情が薄れる。記録しても見返さない
**Day 1 での期待**: 自分の声（感情が乗った状態）で語りかけられることで、当時の感情が蘇る
