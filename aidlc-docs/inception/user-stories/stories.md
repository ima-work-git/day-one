# ユーザーストーリー — Day One

## 構成方針
**ハイブリッド（ペルソナ × ジャーニー）**: ペルソナ軸でグループ化し、各ペルソナ内を「記録 → クローンボイス生成 → 対話 → リマインド」のジャーニー順で整理。

---

## Epic 1: 企業従業員（田中 誠）【最重要】

### US-101: Day One 記録（入社初日・企業研修用フォーマット）
**As a** 企業従業員として、  
**I want to** 企業研修用のデフォルトフォーマットに沿って入社初日の気持ち・動機・目標をテキストで記録したい、  
**So that** 数年後の研修や自分が疲れたときに、当時の自分の言葉で原点回帰できるようにしたい。

**受け入れ基準**:
- [ ] 招待リンクからアカウント作成が3ステップ以内で完了できる
- [ ] 企業研修用デフォルトフォーマット（入社理由・やりたいこと・なりたくない社会人像・未来の自分へのメッセージ）が表示される
- [ ] 各項目にプレースホルダーテキスト（入力例）が表示される
- [ ] 全項目入力後に「次へ：声を録音する」ボタンが表示される
- [ ] 記録完了後に「Day Oneを記録しました」の確認画面が表示される

---

### US-102: フォーマットへの独自項目追加（企業アカウント）
**As a** 企業従業員として、  
**I want to** 管理者が設定した必須項目を記入しつつ、独自の質問項目を最大3項目まで追加したい、  
**So that** 会社が求める記録を確実に残しながら、自分だけの言葉も少し加えられるようにしたい。

**受け入れ基準**:
- [ ] 管理者が設定した必須項目が表示され、変更・削除不可であることが明示される
- [ ] 独自項目を最大3項目まで追加できる（管理者が上限を変更している場合はその値に従う）
- [ ] 項目数が上限に達した場合は追加不可の旨が表示される
- [ ] 追加した独自項目を保存して次回以降も再利用できる

> **設計思想**: 企業アカウントのフォーマットは「管理者の意図通りに動いてもらう」ことを前提とする。必須項目はロックされ、従業員の自由度は最小限に制限される。個人アカウントの「利用者本人が自由に使う」とは根本的に異なる。

---

### US-103: クローンボイス用テキスト読み上げ収録
**As a** 企業従業員として、  
**I want to** 入力したテキストを画面で見ながら声に出して録音したい、  
**So that** 自分の声でクローンボイスが生成され、後で自分らしい音声で語りかけてもらえるようにしたい。

**受け入れ基準**:
- [ ] テキスト入力完了後、入力内容が画面に表示された状態で録音画面に遷移する
- [ ] 録音開始・停止・再録音ができる
- [ ] 録音時間が1分以上になると「十分な音声が収録されました」のガイドが表示される
- [ ] 録音完了後、バックグラウンドでクローンボイス生成が開始される
- [ ] クローンボイス生成完了時にプッシュ通知またはメールで通知される

---

### US-104: 2年目研修での強制振り返り（Day Oneとの再会）
**As a** 入社2年目の企業従業員として、  
**I want to** 会社の研修プログラムの一環として、入社初日に記録した「Day Oneの自分」と向き合いたい、  
**So that** 義務として始めた振り返りが、自分の変化への気づきと原点回帰のきっかけになるようにしたい。

**受け入れ基準**:
- [ ] 管理者が設定したリマインド（入社2年後）が届き、研修セッションへの導線が示される
- [ ] 「2年前のあなたが話しかけています」という通知文言で対話セッションに誘導される
- [ ] 初回の対話セッションでは、入社時に記録した「動機・やりたいこと・なりたくない人物像」がクローンボイスで語りかけられる
- [ ] 対話後に振り返りメモ（自由記述）を保存できる（US-105と同一機能）
- [ ] 研修担当者（山田課長）が設定したスケジュールで自動配信される

---

### US-105: クローンボイスとの双方向対話（任意タイミング）
**As a** 企業従業員として、  
**I want to** 仕事で行き詰まったときや研修の振り返りセッションでいつでも、話しかけたい「Day Oneの自分」を選んで対話を開始したい、  
**So that** リマインド通知を待たずに、自分のタイミングで原点回帰できるようにしたい。

**受け入れ基準**:
- [ ] ホーム画面に登録済みのDay One記録が一覧表示され、話しかけたい「自分」を選べる（例：「入社初日の自分」「3年目研修時の自分」）
- [ ] 選択後3秒以内に対話セッションが開始される
- [ ] 過去の自分の声（クローンボイス）で最初のメッセージが再生される
- [ ] ユーザーの発話に対してクローンボイスが2〜3秒以内に応答を開始する
- [ ] 対話セッション終了後、振り返りメモ（自由記述）を保存できる
- [ ] 対話履歴が一覧で確認できる

---

### US-106: 定期リマインド受信と対話
**As a** 企業従業員として、  
**I want to** 「X年前のあなたが話しかけています」という通知を受け取りたい、  
**So that** 日常の忙しさの中でも、定期的に初心を思い出すきっかけを得られるようにしたい。

**受け入れ基準**:
- [ ] 設定したスケジュール（または管理者設定）でプッシュ通知・メールが届く
- [ ] 通知文言に「X年前のあなたが話しかけています」が含まれる
- [ ] 通知タップで直接対話セッションに遷移できる
- [ ] リマインドスケジュールをユーザー自身が変更・停止できる

---

## Epic 2: 個人ユーザー（佐藤 美咲）

### US-201: 自由タイミングでの Day One 記録
**As a** 個人ユーザーとして、  
**I want to** ダイエット開始日など自分が決めたタイミングで「Day One」を記録したい、  
**So that** 挫折しそうなときに、始めた理由・決意を自分の声で思い出せるようにしたい。

**受け入れ基準**:
- [ ] メールアドレスのみで3分以内にアカウント登録・初回記録が開始できる
- [ ] 「新しいDay Oneを記録する」ボタンからいつでも新規記録を作成できる
- [ ] 記録に任意のタイトル（例：「ダイエット開始」）を付けられる
- [ ] 複数の Day One 記録を管理できる（ダイエット・仕事・趣味など）
- [ ] 写真のアップロードが任意で可能

---

### US-202: フォーマットの自由カスタマイズ（個人アカウント）
**As a** 個人ユーザーとして、  
**I want to** デフォルトフォーマットを自分の用途に合わせて自由に作り変えたい、  
**So that** 自分だけの言葉で「Day Oneの気持ち」を余すことなく記録できるようにしたい。

**受け入れ基準**:
- [ ] 記録作成時にデフォルトフォーマットを選択できる（汎用・ダイエット・スポーツ・受験など）
- [ ] デフォルト項目の文言を自由に編集できる
- [ ] デフォルト項目を自由に削除できる（自分に不要な項目は省ける）
- [ ] 独自の質問項目を最大5項目まで追加できる（デフォルト項目と合わせた合計上限、LLM・TTS処理コストのため）
- [ ] 項目の並び順を自由に変更できる
- [ ] カスタマイズしたフォーマットを保存して次回以降も再利用できる

> **設計思想**: 個人アカウントのフォーマットは「利用者本人が自分のために自由に使う」ことを前提とする。デフォルトはあくまで出発点であり、全項目を自分好みに作り変えられる。企業アカウントの「管理者の意図を守る制約型」とは根本的に異なる。

---

**As a** 個人ユーザーとして、  
**I want to** 入力したテキストを画面で見ながら声に出して録音したい、  
**So that** 自分の声でクローンボイスが生成され、後で自分らしい音声で語りかけてもらえるようにしたい。

**受け入れ基準**:
- [ ] テキスト入力完了後、入力内容が画面に表示された状態で録音画面に遷移する
- [ ] 録音開始・停止・再録音ができる
- [ ] 録音時間が1分以上になると「十分な音声が収録されました」のガイドが表示される
- [ ] 録音完了後、バックグラウンドでクローンボイス生成が開始される
- [ ] クローンボイス生成完了時にプッシュ通知またはメールで通知される

---

### US-204: 挫折しそうなときの緊急対話
**As a** 個人ユーザーとして、  
**I want to** 食欲に負けそうなとき・やめたくなったときに、話しかけたい「Day Oneの自分」を選んで即座に対話したい、  
**So that** 感情的な衝動に負ける前に、始めた理由を思い出して踏みとどまれるようにしたい。

**受け入れ基準**:
- [ ] ホーム画面に登録済みのDay One記録が一覧表示され、話しかけたい「自分」を選べる（例：「ダイエットを決意した自分」「禁煙を決意した自分」）
- [ ] 選択後1タップで対話セッションを開始できる
- [ ] 対話中に「なぜ始めたか」「なりたくない自分」の内容がクローンボイスで語りかけられる
- [ ] ユーザーの発話に対してクローンボイスが2〜3秒以内に応答を開始する
- [ ] セッション終了後に振り返りメモ（自由記述）を保存できる（US-105と同一機能）

---

### US-205: 週次リマインドの設定
**As a** 個人ユーザーとして、  
**I want to** 毎週月曜日など自分で決めたタイミングでリマインドを受け取りたい、  
**So that** 継続的に原点回帰の習慣を作れるようにしたい。

**受け入れ基準**:
- [ ] リマインドの曜日・時間・頻度（毎日・毎週・毎月・特定日）を設定できる
- [ ] 設定変更・一時停止・削除ができる
- [ ] 通知チャネル（プッシュ通知・メール）を選択できる

## Epic 3: 人材開発担当（山田 課長）

### US-301: 組織用記録フォーマットの設定
**As a** 人材開発担当として、  
**I want to** 従業員が記録する際に使う質問項目を組織独自にカスタマイズしたい、  
**So that** 会社として「入社時に必ず残してほしい言葉」を確実に収集し、数年後の研修で活用できるようにしたい。

**受け入れ基準**:
- [ ] デフォルトフォーマット（企業研修用）をベースに項目の追加・編集・削除ができる
- [ ] 設定した項目を「必須」または「任意」に指定できる
- [ ] 従業員側では必須項目の変更・削除ができない（ロック機能）
- [ ] 従業員が独自に追加できる項目数の上限を設定できる（デフォルト：最大3項目）
- [ ] 設定したフォーマットをプレビューで確認できる
- [ ] フォーマットを保存・更新でき、既存ユーザーへの影響（新規記録のみ適用）が明示される

**注記**: MVP後（フェーズ2）で実装。MVP では企業研修用デフォルトフォーマットを固定で使用。

---

### US-302: 企業アカウント登録と従業員招待
**As a** 人材開発担当として、  
**I want to** 企業アカウントを作成し、新入社員に招待リンクを一括送信したい、  
**So that** 入社初日に全員がスムーズにDay Oneを記録でき、数年後の研修で振り返りの機会を提供できるようにしたい。

**受け入れ基準**:
- [ ] 企業名・担当者情報でBtoBアカウントを登録できる
- [ ] CSVまたはメールアドレスの一括入力で招待リンクを送信できる
- [ ] 招待リンクの有効期限を設定できる（デフォルト7日）
- [ ] 招待済み・登録済みの従業員数が確認できる

**注記**: MVP後（フェーズ2）で実装。MVP では管理者が手動でリンクを共有する簡易版で対応。

---

### US-303: リマインドスケジュールの設定
**As a** 人材開発担当として、  
**I want to** 「入社2年後」「入社3年後」などのタイミングで全従業員にリマインドを自動送信したい、  
**So that** 人事担当者が手動でフォローしなくても、社員が自分を見つめ直す機会を定期的に提供できるようにしたい。

**受け入れ基準**:
- [ ] 「入社日から X ヶ月後」「毎年の入社記念日」などのトリガーを設定できる
- [ ] 全従業員または特定グループへの一括送信が設定できる
- [ ] 送信前にプレビューで通知内容を確認できる

**注記**: MVP後（フェーズ2）で実装。

## Epic 4: 学生（鈴木 健太）【将来拡張】

### US-401: 高校1年時の Day One 記録（授業の課題として）
**As a** 高校生として、  
**I want to** 授業の課題として「将来の夢・なりたい自分・なりたくない自分」をDay Oneに記録したい、  
**So that** 数年後に先生から振り返りを促されたとき、当時の自分の言葉と声に再会できるようにしたい。

**受け入れ基準**:
- [ ] 学生アカウント（無料）で登録できる
- [ ] キャリア教育向けのフォーマット項目（将来の夢・なりたい自分・なりたくない自分・今の自分へのメッセージ）が用意されている
- [ ] 学校・塾の招待リンク経由でアカウント作成できる
- [ ] テキスト入力後にクローンボイス用の読み上げ収録ステップがある（US-203と同一フロー）

---

### US-402: 高校3年時の振り返り対話（受験期）
**As a** 受験生として、  
**I want to** 先生から「1年生のときの自分を振り返ってみよう」と促されたとき、高1の自分の声を聞いて対話したい、  
**So that** 「あのときの自分はこんなことを考えていたのか」という気づきを得て、受験を乗り越える力にしたい。

**受け入れ基準**:
- [ ] 2年前に記録したDay Oneにアクセスして対話セッションを開始できる
- [ ] 対話中に「将来の夢」「なりたくない自分」がクローンボイスで語りかけられる
- [ ] 「あのときの自分に恥ずかしくない自分でいたい」という感情が引き出される体験設計になっている

## Epic 5: スポーツ選手（中村 アスリート・プロ野球選手）【将来拡張】

### US-501: 試合後の悔しさ記録
**As a** プロ野球選手として、  
**I want to** 大事な試合で打てなかった直後の悔しさ・決意を感情が乗った状態で記録したい、  
**So that** 時間が経って感情が薄れても、当時の気持ちを練習の原動力にできるようにしたい。

**受け入れ基準**:
- [ ] 試合直後でも30秒以内に記録を開始できるシンプルなUI
- [ ] 音声録音を最優先にした記録フロー（テキストは後から補足可能）
- [ ] スポーツ用デフォルトフォーマット（悔しさ・決意・目標）が選択できる
- [ ] デフォルト項目の編集・削除・独自項目の追加が可能
- [ ] テキスト補足後にクローンボイス用の読み上げ収録ステップがある（US-203と同一フロー）

---

### US-502: 練習前の自己対話
**As a** プロ野球選手として、  
**I want to** 練習前に過去の自分の声で「なぜ練習するか」「あの悔しさ」を聞きたい、  
**So that** 毎日の練習に意味を感じ、手を抜かずに取り組めるようにしたい。

**受け入れ基準**:
- [ ] 「練習前モード」として短時間（1〜2分）の対話セッションを開始できる
- [ ] 試合後に記録した悔しさ・決意の内容がクローンボイスで再生される
