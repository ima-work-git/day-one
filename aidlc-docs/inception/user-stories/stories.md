# ユーザーストーリー — Day 1

## 構成方針
**ハイブリッド（ペルソナ × ジャーニー）**: ペルソナ軸でグループ化し、各ペルソナ内を「記録 → クローンボイス生成 → 対話 → リマインド」のジャーニー順で整理。

**MVP の境界**: MVP は BtoB 研修デモとして実施するが、実装対象は従業員本人のコア体験である。企業管理者向けの組織テンプレート編集、一括招待、自動リマインド配信、利用状況ダッシュボードはフェーズ2で実装する。MVP では運営者が研修用テンプレート・参加リンク・再会導線を手動で準備する。

---

## Epic 1: 企業従業員（田中 誠）【最重要】

### US-101: Day 1 記録（入社初日・企業研修用フォーマット）
**As a** 企業従業員として、
**I want to** 企業研修用のデフォルトフォーマットに沿って入社初日の気持ち・動機・目標をテキストで記録したい、
**So that** 数年後の研修や自分が疲れたときに、当時の自分の言葉で原点回帰できるようにしたい。

**受け入れ基準**:
- [ ] 研修用参加リンク、デモアカウント、または通常登録からアカウント作成が3ステップ以内で完了できる
- [ ] 企業研修用デフォルトフォーマット（入社理由・やりたいこと・なりたい社会人像・なりたくない社会人像・未来の自分へのメッセージ）が表示される
- [ ] 各項目にプレースホルダーテキスト（入力例）が表示される
- [ ] 全項目入力後に「次へ：声を録音する」ボタンが表示される
- [ ] 記録完了後に「Day 1を記録しました」の確認画面が表示される

---

### US-102: 企業研修用固定フォーマットへの独自項目追加
**As a** 企業従業員として、
**I want to** 研修用にあらかじめ用意された必須項目を記入しつつ、独自の質問項目を最大3項目まで追加したい、
**So that** 会社が求める記録を確実に残しながら、自分だけの言葉も少し加えられるようにしたい。

**受け入れ基準**:
- [ ] 企業研修用デフォルトフォーマットの必須項目が表示され、変更・削除不可であることが明示される
- [ ] 独自項目を最大3項目まで追加できる
- [ ] 項目数が上限に達した場合は追加不可の旨が表示される
- [ ] 追加した独自項目を保存して次回以降も再利用できる

> **設計思想**: MVP では企業研修用デフォルトフォーマットを固定で使い、従業員本人のコア体験を検証する。組織ごとの項目編集・必須項目設定・上限変更は、企業管理者向け機能としてフェーズ2で実装する。

---

### US-103: クローンボイス用音声収録
**As a** 企業従業員として、
**I want to** 自分の声で「Day 1 の気持ち」を録音したい、
**So that** 後で過去の自分と双方向対話するときに、過去の自分の声で応えてもらえるようにしたい。

**受け入れ基準**:
- [ ] 録音前に「クローンボイス生成・第三者 API（ElevenLabs）への音声送信・本人以外の声を登録しない」への同意ダイアログが表示される
- [ ] 同意していない場合は録音画面に進めない
- [ ] テキスト入力完了後、参考として直前の入力内容が表示された状態で録音画面に遷移する
- [ ] 録音開始・停止・再録音ができる
- [ ] 録音中に音量メーターが表示される
- [ ] 録音時間が 30 秒未満では「次へ」ボタンが有効にならない
- [ ] 録音時間が 1 分以上になると「十分な音声が収録されました」のガイドが表示される
- [ ] 録音完了後、バックグラウンドでクローンボイス生成が開始される
- [ ] クローンボイス生成完了時にメールまたは画面上のステータスで通知される（プッシュ通知はフェーズ2）
- [ ] クローンボイス生成失敗時は通常 TTS にフォールバックされ、対話は継続できる（NFR-07）

---

### US-104: 2年目研修での振り返り（Day 1との再会）
**As a** 入社2年目の企業従業員として、
**I want to** 会社の研修プログラムの一環として、入社初日に記録した「Day 1の自分」と向き合いたい、
**So that** 研修で案内された振り返りが、自分の変化への気づきと原点回帰のきっかけになるようにしたい。

**受け入れ基準**:
- [ ] MVP では運営者が共有した研修用リンク、または簡易メール通知から研修セッションへの導線が示される
- [ ] 「2年前のあなたが話しかけています」という通知文言で対話セッションに誘導される
- [ ] 初回の対話セッションの応答が、入社時に記録した「動機・やりたいこと・なりたい人物像・なりたくない人物像」を引用または踏まえている（System Prompt に注入される）
- [ ] ユーザーの発話に対してクローンボイスが 2〜3 秒以内に応答を開始する（双方向対話）
- [ ] 対話後に振り返りメモ（自由記述）を保存できる（US-105と同一機能）
- [ ] 【フェーズ2】研修担当者（山田課長）が設定したスケジュールで自動配信される

---

### US-105: クローンボイスとの双方向対話（任意タイミング）
**As a** 企業従業員として、
**I want to** 仕事で行き詰まったときや研修の振り返りセッションでいつでも、話しかけたい「Day 1の自分」を選んで対話を開始したい、
**So that** リマインド通知を待たずに、自分のタイミングで原点回帰できるようにしたい。

**受け入れ基準**:
- [ ] ホーム画面に登録済みのDay 1記録が一覧表示され、話しかけたい「自分」を選べる（例：「入社初日の自分」「3年目研修時の自分」）
- [ ] 選択後3秒以内に対話セッションが開始される
- [ ] 過去の自分の声（クローンボイス）で最初のメッセージが再生される
- [ ] ユーザーの発話に対してクローンボイスが2〜3秒以内に応答を開始する
- [ ] 対話セッション終了後、振り返りメモ（自由記述）を保存できる
- [ ] 対話履歴が一覧で確認できる
- [ ] 【フェーズ2】2回目以降の対話では、前回の会話内容を踏まえた問いかけから始まる（例：「前回、転職を考えていると言っていましたね。その後どうですか？」）

---

### US-106: 定期リマインド受信と対話
**As a** 企業従業員として、
**I want to** 「X年前のあなたが話しかけています」という通知を受け取りたい、
**So that** 日常の忙しさの中でも、定期的に初心を思い出すきっかけを得られるようにしたい。

**受け入れ基準**:
- [ ] MVP ではユーザー自身の簡易設定、または運営者が共有したメール・リンクで対話セッションに遷移できる
- [ ] 通知文言に「X年前のあなたが話しかけています」が含まれる
- [ ] 通知内リンクまたは研修用リンクから直接対話セッションに遷移できる
- [ ] リマインドスケジュールをユーザー自身が変更・停止できる
- [ ] 【フェーズ2】管理者が入社日・研修日を起点に一括リマインドを設定できる

## Epic 2: 個人ユーザー（佐藤 美咲）【共通コア実装・将来横展開】

### US-201: 自由タイミングでの Day 1 記録
**As a** 個人ユーザーとして、
**I want to** ダイエット開始日など自分が決めたタイミングで「Day 1」を記録したい、
**So that** 挫折しそうなときに、始めた理由・決意を自分の声で思い出せるようにしたい。

**受け入れ基準**:
- [ ] メールアドレスのみで3分以内にアカウント登録・初回記録が開始できる
- [ ] 「新しいDay 1を記録する」ボタンからいつでも新規記録を作成できる
- [ ] 記録に任意のタイトル（例：「ダイエット開始」）を付けられる
- [ ] 複数の Day 1 記録を管理できる（ダイエット・仕事・趣味など）
- [ ] 写真のアップロードが任意で可能

---

### US-202: フォーマットの自由カスタマイズ（個人アカウント）
**As a** 個人ユーザーとして、
**I want to** デフォルトフォーマットを自分の用途に合わせて自由に作り変えたい、
**So that** 自分だけの言葉で「Day 1の気持ち」を余すことなく記録できるようにしたい。

**受け入れ基準**:
- [ ] 記録作成時にデフォルトフォーマットを選択できる（汎用・ダイエット・スポーツ・受験など）
- [ ] デフォルト項目の文言を自由に編集できる
- [ ] デフォルト項目を自由に削除できる（自分に不要な項目は省ける）
- [ ] 独自の質問項目を最大5項目まで追加できる（デフォルト項目と合わせた合計上限、LLM・TTS処理コストのため）
- [ ] 項目の並び順を自由に変更できる
- [ ] カスタマイズしたフォーマットを保存して次回以降も再利用できる

> **設計思想**: 個人アカウントのフォーマットは「利用者本人が自分のために自由に使う」ことを前提とする。デフォルトはあくまで出発点であり、全項目を自分好みに作り変えられる。フェーズ2の企業管理者向け制約型テンプレートとは異なるが、記録・音声収録・対話のコア体験は共通である。

## Epic 3: 人材開発担当（山田 課長）

### US-301: 組織用記録フォーマットの設定
**As a** 人材開発担当として、
**I want to** 従業員が記録する際に使う質問項目を組織独自にカスタマイズしたい、
**So that** 会社として「入社時に必ず残してほしい言葉」を確実に収集し、数年後の研修で活用できるようにしたい。

**受け入れ基準**:
- [ ] デフォルトフォーマット（企業研修用）をベースに項目の追加・編集・削除ができる
- [ ] 設定した項目を「必須」または「任意」に指定できる
- [ ] 従業員側では必須項目の変更・削除ができない（ロック機能）
- [ ] 従業員が独自に追加できる項目数の上限を設定できる（デフォルト：最大3項目）
- [ ] 設定したフォーマットをプレビューで確認できる
- [ ] フォーマットを保存・更新でき、既存ユーザーへの影響（新規記録のみ適用）が明示される

**注記**: MVP後（フェーズ2）で実装。MVP では運営者が選んだ企業研修用デフォルトフォーマットを固定で使用。

---

### US-302: 企業アカウント登録と従業員招待
**As a** 人材開発担当として、
**I want to** 企業アカウントを作成し、新入社員に招待リンクを一括送信したい、
**So that** 入社初日に全員がスムーズにDay 1を記録でき、数年後の研修で振り返りの機会を提供できるようにしたい。

**受け入れ基準**:
- [ ] 企業名・担当者情報でBtoBアカウントを登録できる
- [ ] CSVまたはメールアドレスの一括入力で招待リンクを送信できる
- [ ] 招待リンクの有効期限を設定できる（デフォルト7日）
- [ ] 招待済み・登録済みの従業員数が確認できる

**注記**: MVP後（フェーズ2）で実装。MVP では運営者が参加リンクまたはデモアカウントを手動で共有する。

---

### US-303: リマインドスケジュールの設定
**As a** 人材開発担当として、
**I want to** 「入社2年後」「入社3年後」などのタイミングで全従業員にリマインドを自動送信したい、
**So that** 人事担当者が手動でフォローしなくても、社員が自分を見つめ直す機会を定期的に提供できるようにしたい。

**受け入れ基準**:
- [ ] 「入社日から X ヶ月後」「毎年の入社記念日」などのトリガーを設定できる
- [ ] 全従業員または特定グループへの一括送信が設定できる
- [ ] 送信前にプレビューで通知内容を確認できる

**注記**: MVP後（フェーズ2）で実装。

## Epic 4: 学生（鈴木 健太）【将来拡張】

### US-401: 高校1年時の Day 1 記録（授業の課題として）
**As a** 高校生として、
**I want to** 授業の課題として「将来の夢・なりたい自分・なりたくない自分」をDay 1に記録したい、
**So that** 数年後に先生から振り返りを促されたとき、当時の自分の言葉と声に再会できるようにしたい。

**受け入れ基準**:

- [ ] テキスト入力後にクローンボイス用の音声収録ステップがある（US-203 と同一フロー）

## Epic 5: スポーツ選手（中村 アスリート・プロ野球選手）【将来拡張】

### US-501: 試合後の悔しさ記録
**As a** プロ野球選手として、
